# Digitaler Werkzeugschrank

Öffentlicher, statischer Präsentationsprototyp des TMS-Kundenportals von Gudel Werkzeuge – inklusive interaktivem Analyse-Dashboard und echtem kamera-basiertem QR-Scan für das Demo-Werkzeug `GW-SB-000184`.

**Live:** https://jgudel-ctrl.github.io/digitaler-werkzeugschrank/

**Demo-QR-Code:** https://jgudel-ctrl.github.io/digitaler-werkzeugschrank/demo-qr-gw-sb-000184.jpg

Enthalten sind ausschließlich strukturierte Dummy-Daten. Keine realen Kunden-, Preis-, Rechnungs- oder Auftragsdaten.
